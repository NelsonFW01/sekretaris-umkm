⚠️ Realtime Database belum dibuat di project Firebase kamu. Config project "sekretaris-umkm" sudah ditempel di kode, tapi databaseURL masih kosong karena Realtime Database belum diaktifkan — itu sebabnya muncul error.

Langkah terakhir (±1 menit):
1. Buka console.firebase.google.com → project sekretaris-umkm.
2. Di sidebar kiri klik Build → Realtime Database (bukan Firestore).
3. Klik "Create Database", pilih lokasi server (mis. Singapore/asia-southeast1), lalu pilih "Start in test mode".
4. Setelah dibuat, akan muncul URL seperti https://sekretaris-umkm-default-rtdb.asia-southeast1.firebasedatabase.app — salin persis URL itu.
5. Tempel URL itu ke databaseURL di awal file index.html, ganti "GANTI_DATABASE_URL".
6. Simpan, upload ulang ke GitHub Pages.
